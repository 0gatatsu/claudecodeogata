# iOSショートカット 作成手順

「燃えないごみ」の収集日をiOSカレンダーに一括登録するショートカットです。  
GitHub Actionsで更新されたカレンダーデータ（JSON）を取得して、iOSカレンダーに登録します。  
TimeTreeはiOSカレンダーと同期する設定にしてください。

---

## 事前準備

1. **TimeTreeとiOSカレンダーを同期する設定を確認**
   - TimeTree → 設定 → カレンダー連携 → 「iOSカレンダーに追加」をON

2. **iOSカレンダーに「家族用カレンダー」があることを確認**

---

## ショートカットの作成手順

iOSの「ショートカット」アプリを開き、右上の「+」から新規ショートカットを作成します。

### ステップ 1: JSONデータを取得する

アクション追加 → 「URLの内容を取得」  
- URL: `https://0gatatsu.github.io/claudecodeogata/calendar.json`

### ステップ 2: 日付リストを取り出す

アクション追加 → 「辞書の値を取得」  
- キー: `funen_dates`

### ステップ 3: 件数チェック（既存イベントの重複防止）

アクション追加 → 「もし」  
- 条件: 「URLの内容（辞書の値）」の「項目数」が「0」に等しい

アクション追加（「もしの場合」内） → 「通知を表示」  
- 本文: 「カレンダーデータが空です。GitHub Actionsを実行してください。」

アクション追加 → 「ショートカットを終了」

アクション追加 → 「それ以外の場合」

### ステップ 4: 各日付にイベントを追加する

アクション追加（「それ以外の場合」内） → 「それぞれを繰り返す」  
（対象: 「辞書の値」の出力）

繰り返しブロック内：

#### 4-1. 日付に変換
アクション追加 → 「日付を取得」  
- 入力: 「繰り返し項目」

#### 4-2. 過去の日付をスキップ
アクション追加 → 「もし」  
- 条件: 「日付」が「現在の日付」より後

#### 4-3. イベントを追加（「もしの場合」内）
アクション追加 → 「新規イベントを追加」  
- タイトル: `燃えないごみ`
- カレンダー: （家族で共有しているカレンダーを選択）
- 開始日: 「日付」
- 終了日: 「日付」
- 終日: ON
- アラート: 前日 午前9時

#### 4-4. 繰り返し終了
アクション追加 → 「繰り返し終了」

### ステップ 5: 完了通知

アクション追加 → 「通知を表示」  
- 本文: `燃えないごみの予定を登録しました`

---

## 自動実行の設定（iOSオートメーション）

毎年4月7日に自動でショートカットを実行するよう設定します。

1. ショートカットアプリ → 「オートメーション」タブ
2. 「+」→「個人用オートメーション」→「特定の日付」
3. 日付: 毎年 4月7日 09:00
4. 繰り返し: 毎年
5. アクション追加 → 「ショートカットを実行」→ 上で作成したショートカットを選択
6. 「実行前に確認」: OFF（完全自動化したい場合）

---

## 動作の流れ

```
毎年4月5日
  → GitHub Actions が諫早市PDFを解析
  → calendar.json を自動更新

毎年4月7日（iOSオートメーション）
  → ショートカットが calendar.json を取得
  → 1年分の「燃えないごみ」をiOSカレンダーに登録
  → TimeTreeに自動同期
```
