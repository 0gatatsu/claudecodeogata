# iOSショートカット 作成手順（詳細版）

「燃えないごみ」の収集日をiOSカレンダーに一括登録するショートカットです。

---

## 事前準備

1. **iOSの「ショートカット」アプリ**が入っていることを確認（標準インストール済み）
2. **GitHub Actions が正常に実行済み**で、以下のURLにアクセスできることを確認  
   → `https://0gatatsu.github.io/claudecodeogata/calendar.json`
3. **TimeTree → 設定 → カレンダー連携 → iOSカレンダーに追加** をONにする

---

## ショートカットの作成

### アプリを開いて新規作成

1. 「**ショートカット**」アプリを開く
2. 右上の「**＋**」をタップ
3. 画面上部の「**ショートカット名**」をタップして名前を入力：`燃えないごみ登録`
4. 「**アクションを追加**」をタップしてアクションを追加していく

---

### アクション 1：カレンダーデータを取得する

**「URLの内容を取得」を追加**

1. 検索バーに「**URL**」と入力
2. 「**URLの内容を取得**」をタップして追加
3. 追加されたアクション内の「URL」部分をタップして以下を入力：
   ```
   https://0gatatsu.github.io/claudecodeogata/calendar.json
   ```
4. 「方法」は「**GET**」のまま（変更不要）

---

### アクション 2：JSONを辞書に変換する

**「辞書を取得」を追加**

1. 「アクションを追加」をタップ
2. 検索バーに「**辞書**」と入力
3. 「**辞書を取得**」をタップして追加
4. 入力欄に「**URLの内容**」が自動的に入っていることを確認  
   （入っていない場合は入力欄をタップ → 「URLの内容」を選択）

---

### アクション 3：日付リストを取り出す

**「辞書の値を取得」を追加**

1. 「アクションを追加」をタップ
2. 検索バーに「**辞書の値**」と入力
3. 「**辞書の値を取得**」をタップして追加
4. 設定を以下のように変更：
   - 「値」→ 「**値**」のまま（変更不要）
   - 「キー」の欄をタップ → 以下を入力：
     ```
     funen_dates
     ```
   - 「辞書」の欄に「**辞書**」が入っていることを確認

---

### アクション 4：データが空でないか確認する

**「もし」を追加（空チェック）**

1. 「アクションを追加」をタップ
2. 検索バーに「**もし**」と入力
3. 「**もし**」をタップして追加
4. 条件を設定：
   - 左側の入力欄をタップ →「**辞書の値**」を選択
   - 中央の条件をタップ → 「**次のものがない**」を選択
5. 「もしの場合」の下に以下を追加：
   - 「アクションを追加」→「**通知を表示**」を追加
   - 本文：`カレンダーデータがありません。GitHub Actionsを実行してください。`
   - 「アクションを追加」→「**ショートカットを停止**」を追加
6. 「それ以外の場合」の下に残りのアクションを追加していく（次のステップ）

---

### アクション 5：各日付をループして処理する

**「それ以外の場合」の下に「それぞれを繰り返す」を追加**

1. 「それ以外の場合」のすぐ下の「アクションを追加」をタップ
2. 検索バーに「**繰り返す**」と入力
3. 「**それぞれを繰り返す**」をタップして追加
4. 繰り返しの対象：「**辞書の値**」が表示されていることを確認  
   （違う場合はタップして「辞書の値」を選択）

---

### アクション 6（繰り返しの中）：文字列を日付に変換する

**「繰り返す」の中に「日付を取得」を追加**

1. 「繰り返す」と「繰り返し終了」の間の「アクションを追加」をタップ
2. 検索バーに「**日付**」と入力
3. 「**日付を取得**」をタップして追加
4. 設定：
   - 入力欄に「**繰り返し項目**」が入っていることを確認  
     （入っていない場合はタップ→「繰り返し項目」を選択）

---

### アクション 7（繰り返しの中）：過去の日付をスキップする

**「もし」を追加（未来の日付のみ処理）**

1. 「アクションを追加」をタップ
2. 「**もし**」をタップして追加
3. 条件を設定：
   - 左側の入力欄：「**日付**」を選択
   - 中央の条件：「**次のものより後**」を選択
   - 右側：「**現在の日付**」を選択

---

### アクション 8（もしの中）：カレンダーにイベントを追加する

**「もしの場合」の下に「新規イベントを追加」を追加**

1. 「もしの場合」のすぐ下の「アクションを追加」をタップ
2. 検索バーに「**イベント**」と入力
3. 「**新規イベントを追加**」をタップして追加
4. 各項目を設定：

   | 項目 | 設定値 |
   |------|--------|
   | タイトル | `燃えないごみ` と手入力 |
   | カレンダー | 家族で共有しているカレンダーを選択 |
   | 開始日 | 「日付」を選択 |
   | 終了日 | 「日付」を選択 |
   | 終日 | **ON** にする |
   | アラート | **1日前** を選択 |
   | 2回目のアラート | **当日 午前8時** など好みで設定 |

5. 「もし〜終了」と「繰り返し〜終了」がそれぞれ閉じていることを確認

---

### アクション 9：完了メッセージを表示する

**ループの外（「繰り返し終了」の下）に「通知を表示」を追加**

1. 「繰り返し終了」の下の「アクションを追加」をタップ
2. 「**通知を表示**」をタップして追加
3. 本文：`燃えないごみの予定をカレンダーに登録しました`

---

### 完成イメージ（アクションの順序）

```
① URLの内容を取得
   └ https://0gatatsu.github.io/claudecodeogata/calendar.json

② 辞書を取得
   └ 入力: URLの内容

③ 辞書の値を取得
   └ キー: funen_dates

④ もし「辞書の値」が次のものがない
   ├ [もしの場合]
   │   通知を表示「データがありません」
   │   ショートカットを停止
   └ [それ以外の場合]

⑤   それぞれを繰り返す（辞書の値）

⑥     日付を取得（繰り返し項目）

⑦     もし「日付」が「現在の日付」より後
       ├ [もしの場合]
⑧     │   新規イベントを追加
       │   タイトル: 燃えないごみ
       │   カレンダー: 家族カレンダー
       │   開始・終了: 日付（終日）
       │   アラート: 1日前
       └ もし終了

       繰り返し終了

もし終了

⑨ 通知を表示「登録しました」
```

## 自動実行の設定（毎年4月7日に自動で動く）

1. ショートカットアプリ → 下部「**オートメーション**」タブをタップ
2. 右上「**＋**」→「**個人用オートメーションを作成**」
3. 「**特定の日付**」をタップ
4. 設定：
   - 日付：**4月7日**
   - 時刻：**午前9:00**
   - 繰り返し：**毎年**
5. 「次へ」→「**アクションを追加**」
6. 「**ショートカットを実行**」を選択
7. 「ショートカット」欄で「**燃えないごみ登録**」を選択
8. 「次へ」→「**実行前に確認**」を**OFF**にする（完全自動化）
9. 「完了」をタップ

---

## 動作確認

作成後、すぐに手動でショートカットを1回実行して動作確認してください。

1. ショートカットアプリ → 「燃えないごみ登録」をタップ
2. カレンダーアプリを開いて「燃えないごみ」が追加されているか確認
3. TimeTreeを開いてカレンダーに反映されているか確認
